# ViVideo

ViVideo 是一个本地视频优先的对话式探索应用。用户提出感兴趣的领域后，模型先澄清具体方向，后台同时准备相关视频；需求明确后，展示匹配的本地缓存并在网页中播放。

## 主要功能

- 学习、漫游两个独立空间，分别保存会话、记忆、偏好与视频缓存。
- 支持多套模型 API 配置，通过 MCP 工具完成视频检索、记忆更新和偏好提议。
- 后台下载、校验和缓存视频，支持任务恢复、容量管理与站内播放。
- 长期偏好经用户确认后保存；有效观看严格超过视频总时长的 25% 才记录。
- 推荐条目不超过 3 条时静态显示，更多条目采用循环滚动。

首次准备需要下载时间，视频就绪后才会作为可播放推荐展示。来源平台和网络条件会影响下载可用性。

## 技术栈与运行范围

前端使用原生 HTML/CSS/JavaScript；后端使用 FastAPI、ZMQ、Python 对话与下载 Worker、MCP、SQLite 和 Markdown 记忆。媒体处理使用 yt-dlp、FFmpeg、ffprobe，Node 用于相关下载运行时。

需要 Python 3.11+，当前支持 Linux/macOS，Windows 使用 WSL。不要求 GPU 或 CUDA。当前是面向可信访问者的单用户应用。
